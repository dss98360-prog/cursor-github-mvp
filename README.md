# Нейро-копирайтер для бизнеса

Учебное веб-приложение для создания демонстрационных бизнес-текстов по заданным параметрам.

Проект выполнен в рамках задания «MVP в Cursor → улучшение через GitHub (ветки + PR)».

## Возможности MVP

- ввод названия бизнеса или продукта;
- ввод темы и ключевых преимуществ;
- выбор формата текста;
- выбор тона коммуникации;
- локальная генерация демонстрационного текста;
- проверка обязательных полей;
- очистка формы;
- адаптивный интерфейс для компьютеров и мобильных устройств.

Приложение работает локально и не требует подключения к внешнему API.

## Используемые технологии

- React;
- TypeScript;
- Vite;
- CSS.
